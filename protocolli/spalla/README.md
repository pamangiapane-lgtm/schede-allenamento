# Protocolli Spalla

## Patologie target

| Codice | Nome | Popolazione volley | File |
|---|---|---|---|
| SPA | Tendinopatia cuffia / Impingement sub-acromiale | Schiacciatrici, opposti | seduta_A_* |
| SPB | Instabilità anteriore / Capsula articolare lassa | Pallegiatrici, liberi | seduta_B_* |
| SPG | Prevenzione generica | Tutte le atlete | programma_generico* |

## Scegli il protocollo

```
Dolore attivo durante o dopo allenamento?
  → SPA se dolore laterale / anteriore con braccio elevato (arco doloroso)
  → SPB se sensazione di "spalla che va fuori" o instabilità

Solo prevenzione, nessun dolore?
  → SPG programma_generico_preventivo
```

## Dosaggio orientativo

| Fase | Frequenza | Durata seduta |
|---|---|---|
| Acuta (dolore >4/10) | 3×/settimana | versione 10 min |
| Sub-acuta (dolore 2-4/10) | 3×/settimana | versione full |
| Rinforzo (dolore <2/10) | 2×/settimana | versione full |
| Mantenimento | 1×/settimana | versione 10 min |

## Soglia di stop

Qualsiasi esercizio che provoca dolore >3/10 durante l'esecuzione → skip quell'esercizio, non la seduta.
