# Protocolli Funzionali — Marsala Volley A2

Raccolta di protocolli standardizzati per prevenzione e recupero.  
Ogni sottocartella = una problematica articolare o funzionale.

## Struttura

```
protocolli/
  spalla/          Cuffia, impingement, instabilità capsulare, prevenzione
  (ginocchio/)     futuro
  (lombare/)       futuro
```

## Convenzioni

- `*_full.md` = seduta completa 45-50 min
- `*_10min.md` = versione condensata pre/post allenamento
- `*_3fasi.md` = programma progressivo 8-10 settimane
- `*_generico.md` = protocollo preventivo per atleti sani

## Aggiornamento

I protocolli sono basati su metodologia ELAV Recovery + letteratura S&C per volley.  
Ultima revisione: agosto 2026.
